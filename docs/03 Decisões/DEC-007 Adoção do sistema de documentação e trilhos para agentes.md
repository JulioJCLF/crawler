# DEC-007 — Adoção do sistema de documentação e trilhos para agentes

## Contexto
O projeto tinha boas especificações técnicas, mas não tinha requisitos numerados, registro de decisões, pedidos de mudança nem regras únicas para agentes de IA.

## Decisão
Adotar a mesma estrutura usada no V360: requisitos numerados, decisões, pedidos de mudança, registro de sessões, painéis gerados e `AGENTS.md` como única cópia das regras.

## Consequências
- Toda sessão de trabalho passa a fechar com registro e painéis atualizados.
- Os requisitos REQ-001 a REQ-016 foram escritos a partir do código existente e precisam de conferência.
- As especificações técnicas continuam onde estavam.

## Evidências
`AGENTS.md`, `docs/`, `scripts/gerar-paineis.py`
