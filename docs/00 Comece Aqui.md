# 👋 Comece aqui — Arsenal Crawler

Esta é a documentação viva do projeto. Tudo que foi decidido, pedido ou construído mora aqui.

## Para onde ir
| Se você quer… | Abra |
|---|---|
| Entender o projeto | [[Visão Geral do Projeto]] |
| Ver o que está sendo feito | Painéis → Requisitos por fase |
| Saber por que algo foi decidido | `03 Decisões` |
| Pedir uma mudança | [[Como Pedir uma Mudança]] |
| Ver o que mudou recentemente | [[Registro de Mudanças]] |

## Como funciona
1. Cada coisa a ser feita vira um **requisito numerado**, escrito em linguagem simples.
2. Toda escolha importante vira uma **decisão** registrada, com o motivo.
3. Quem quer mudar algo faz um **pedido de mudança** em vez de editar documento.
4. Toda sessão de trabalho deixa um **registro**, então nada se perde.
5. Os **painéis** são gerados automaticamente: não edite.

> [!tip] Convenção de nomes
> `REQ-001`, `DEC-001`, `PM-001`. O número nunca é reaproveitado.
